== Layout, extraction and remaining verification

=== Layout work state

The available layout image is a placement draft with separated structures. It documents work toward the cell but does not show a finished connected, tileable cell or a DRC/LVS-clean result.

.Unlaid placement draft; not a signed-off layout
image::6t_sram_layout_unlaid.png[Unfinished separated bitcell placement structures,align=center,width=760]

The handout requires WL horizontal and BL/BLB vertical, with abutting mirrored cells able to share contacts and supply rails. The completed cell needs a measured boundary area in μm² and in stem:[F^2], where the current handout sets stem:[F=10\,\mathrm{nm}]. The conversion will be stem:[A_{F^2}=10^4 A_{\mu m^2}] when the actual area is known. DRC and LVS summaries must accompany the image. None of these values or logs are in the repository.

After layout signoff, PEX must provide the bitline-node and wordline-node capacitance of *one cell*. Those extracted loads feed the later 16 × 4 macro and the 15-extra-cell functional surrogate. No capacitance is inferred from the schematic or placement draft.

The post-layout supply table cannot be populated with the existing schematic value. The transient column load also needs the extracted per-cell BL capacitance. The next evidence sequence is: finish layout, record DRC/LVS and area, extract, then run the full set of benches at the current handout supplies.

=== Design decision

Increasing PD strength relative to PG improved the measured schematic read margin. The larger PD may cost layout area and parasitic load, and γ=1 still needs a quantitative write result. If the extracted cell misses read or write margin, revise PD/PG/PU sizing and repeat both schematic and extracted checks before the cell is tiled into Part 2.
