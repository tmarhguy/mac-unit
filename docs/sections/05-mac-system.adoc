== MAC unit (Part 3)

Two Part 2 macros hold W and X. A static-CMOS array multiplier, a 12-bit ripple accumulator, a 4-bit counter and `controller_mac` compute the dot product. The macro output latch is the only pipeline stage: SRAM access and arithmetic share one period. Tests A, B and C all pass at 10, 4.0 and **2.5 ns**. At 2.0 ns, A finishes at 0x34D and C at 0x320 (pass) while B finishes at 0xC10 instead of 0xE10 (fail). At 1.75 ns and 1.5 ns all three fail. Selected stem:[T_{CLK}=2.5] ns (400 MHz), stem:[t_{dot}=17\times2.5=42.5] ns. Energy and FOM use that same period. All of this chapter is schematic-level.

link:report-part3.pdf[Part 3 PDF] is the Gradescope write-up (figures, DFF tables, energy integrals).

=== Datapath

Leaf cells are static CMOS, L=18 nm. The 4×4 array multiplier is AND rows plus ripple full adders. Exhaustive 256/256 products match; measured worst case is 1.14–1.24 ns (vector 244, B=15). Hand logical effort is ~1.85 ns. The 12-bit ripple adder is twelve of the same full adder (148 fins each).

=== Sequencer

`controller_mac` plus `counter_4b`: START is sampled on a rising CLK; COUNT walks 0–15; both macros are read in cycles 0–15; VALID delays ACC_EN so accumulate occupies cycles 1–16; DONE rises on cycle 17. `tb_controller_mac`: **60/60** vector checks; `tb_counter4b`: **38/38**.

=== Energy and FOM

Single VDD pin on `tb_top`. Window 82–126 ns (44 ns clip; latency is 42.5 ns).

[stem]
++++
E_{dot}=-V_{DD}\int_{82\,\mathrm{ns}}^{126\,\mathrm{ns}} I_{V0+}\,\mathrm{d}t
++++

[cols="1,1,1,1",options="header"]
|===
| Test | ACC | stem:[E_{dot}] (meas.) | stem:[E_{\mathrm{MAC}}=E_{dot}/16]
| A | 0x34D | **8.870 pJ** | 0.5544 pJ/MAC
| B | 0xE10 | 15.29 pJ | 0.9556 pJ/MAC
| C | 0x320 | 9.500 pJ | 0.5938 pJ/MAC
|===

.Test A energy, 8.870 pJ
image::tb_top_A_eng_2p5.png[ViVA energy integral for Test A at 2.5 ns,align=center,width=700]

Memory vs logic is not a second Spectre split (one VDD). From Part 2: stem:[E_{\mathrm{macro/cyc}}\approx86.7] fJ at 2.5 ns → stem:[E_{\mathrm{mem}}\approx2.77] pJ (est.) for two macros × 16 addresses. Test A logic ≈ 6.10 pJ (0.38 pJ/MAC without memory, est.). Bitline restore is only 0.29 pJ of that 2.77 pJ; the clocked Part 2 controller dominates.

[stem]
++++
\mathrm{FOM}_{MAC}=\mathrm{Area}\cdot E_{dot}\cdot t_{dot}
=291.8\,\mu\mathrm{m}^{2}\times 8.870\,\mathrm{pJ}\times 42.5\,\mathrm{ns}
=1.100\times10^{5}
++++

reported as stem:[1.1\times10^{5}] µm²·pJ·ns.

=== What limited the design

The period is set by the multiply-accumulate path (~1.2 ns multiplier, then 12-bit ripple and stem:[t_{su}=40] ps), not the 488 ps SRAM read. Ripple arithmetic was kept for one verified full adder. A chip-select on the macros would cut the clocked memory energy; a pipeline register after the multiplier would split SRAM and arithmetic at a second extra cycle (18).
