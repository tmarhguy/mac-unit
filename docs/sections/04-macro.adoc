== SRAM Macro (Part 2 — roadmap)

NOTE: Roadmap — Part 2 hardware does not exist yet. Every value in

synchronous SRAM macro. This chapter is a stub with fixed headings
so Part 2 bring-up only fills tables and drops figures.

=== Tiling and floorplan

* Wordline horizontal, bitline pair vertical (from <<bitcell,Bitcell>>).
* 16 rows × 4 columns of the exact Part 1 cell — no resized one-off.
* Per-cell stem:[C_{\mathrm{BL}}] / stem:[C_{\mathrm{WL}}] scale to
full-line loads here.

Macro area, aspect ratio, pinout: TBD.

=== Periphery

* Row decoder (4-to-16) driving wordlines.
* Precharge / equalize on the bitline pairs.
* Sense or full-swing read path per handout; write drivers.
* Control: clock, chip-select, write-enable, address, data in/out.

Periphery schematic and timing arcs: TBD.

=== Timing and loads

* Read path: WL rise → bitline develop → sense/sample.
* Write path: setup → WL pulse → hold.
* Bitline load = 16 × stem:[C_{\mathrm{BL}}] + periphery;
wordline load = 4 × stem:[C_{\mathrm{WL}}] + wire (extracted).
