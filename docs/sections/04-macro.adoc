== SRAM macro (Part 2)

The Part 1 cell is tiled into a 16×4 synchronous SRAM (`sram_macro`) with a 4-to-16 predecoder, per-column precharge, write driver, 2:2 read path and output latch, and a delay-chain controller. Wordlines run horizontally; bitline pairs run vertically. The 64 cells keep the Part 1 sizes (no one-off resize). Bitline stand-in load is stem:[C_{BL}=3.5] fF (`cbw` plus 16 × 180 aF). Simulations in this chapter are schematic-level. Area uses stem:[D=28] from Part 1 except the array, which is 64 × 0.389 µm².

=== Periphery

Write driver NMOS stacks are **nfin=8** (smallest that writes at 3.5 fF is nfin=5; nfin=8 writes in 96 ps with BLB staying above ~0.34 V). Minimum write pulse at 50% is 100–120 ps; design pulse ~140 ps.

=== Decoder

Chosen decoder is a 2–2 predecode (NAND3 + `inv_2x` + row NAND2 + `inv_drv`). Logical effort with B=8 (address fan-out) predicts 182 ps address-to-wordline (stem:[\tau=10.5] ps from FO4=53 ps). Measured A⟨0⟩ path: 106 ps (new row rising) / 112 ps (old row falling).

=== Full-macro bench

`tb_sram_macro` writes 16 words, reads them, writes the complement, and reads again. err1 / err2 / err3 (M-weighted DOUT error) all pass at 173.8 µV against a 0.1 V spec. Worst-case access at stem:[T_{CLK}=0.69] ns is 488 ps on a read of 1.
