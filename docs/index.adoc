== Project overview

ESE 5700 Project 1 begins with a 6T SRAM cell for a later 16 × 4 SRAM macro and 4-bit multiply-accumulate unit. The current assignment uses *Cadence GPDK 18 nm* at nominal stem:[V_{DD}=0.8\,\mathrm V]. The evidence in this repository is a sized Virtuoso schematic, handwritten read analysis, a worked write derivation, testbench schematics, and three measured *schematic* read butterflies. Layout signoff and post-layout results are still open.

.Original Virtuoso 6T cell schematic with device sizes
image::bitcell-schematic.png[Symmetric six transistor SRAM schematic in Virtuoso,align=center,width=760]

[cols="1,1,1",options="header"]
|===
| Pull-down ratio β | Schematic read SNM | Read-disturbed zero node
| 1.0 | 126.6 mV | 134.3 mV
| 1.5 | 145.8 mV | 96.6 mV
| *2.0, candidate* | *156.3 mV* | *77.1 mV*
|===

The selected schematic candidate has β=2 and pull-up ratio γ=1. The 29.7 mV improvement over β=1 is a measured *schematic* result at 0.8 V. It is not yet a post-layout claim.
